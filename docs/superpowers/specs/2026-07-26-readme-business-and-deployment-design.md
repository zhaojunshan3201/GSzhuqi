# README 业务说明与技术部署文档设计

## 目标

将已有乱码且过时的 README 完整重写为 UTF-8 中文文档，统一系统名称为“数智化注采管理系统”，同时满足业务介绍、演示说明和本地技术部署需求。

## 文档结构

### 业务说明

1. 系统定位与适用范围。
2. 注汽管理业务闭环：选井决策、方案与计划、施工监控、焖井转抽、生产响应、效果评价、优化复盘。
3. 主要功能模块：系统概览、注采驾驶舱、注采状态地图、注窜项目台账、各流程模块、注汽优化预测、运行报告。
4. 数智化能力：可解释选井评分、同类井匹配、四情景产量预测、Top 3 最优运行推荐、注窜影响与治理闭环、自动报告。
5. 角色和数据边界：游客只读、管理员维护；当前数据源为本地 SQLite 和导入数据，不依赖单位生产数据库。

### 技术部署附录

1. 技术栈和关键目录。
2. Node.js 环境、依赖安装、开发启动和本地访问地址。
3. 环境变量与生产启动要求，包括认证密钥。
4. SQLite 数据文件和可选 Oracle 数据同步边界。
5. 接口能力概览、测试、类型检查和构建命令。
6. 当前限制及后续接入生产数据库或实时接口的扩展方向。

## 非目标

不修改应用代码、数据库结构、接口实现、权限实现或部署脚本；不承诺当前未接入的实时生产数据库能力。

## 验收标准

- README 无乱码，使用 UTF-8 中文。
- 名称、菜单和功能与当前系统一致。
- 业务能力与技术部署信息均可独立阅读。
- 文档说明本地默认访问地址、测试和构建命令。
- 仅 README 与文档流程文件被提交；随后推送 main。
