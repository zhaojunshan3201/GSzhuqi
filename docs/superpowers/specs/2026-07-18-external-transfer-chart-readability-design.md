# 外输跟踪图表可读性优化设计

## 目标

优化“外输跟踪”页面的图表横坐标和系列视觉区分：长时间范围内日期标签不再拥挤，且不同指标可在不依赖 Oracle 客户端的情况下清晰辨识。

## 范围

仅调整 `src/components/ExternalTransferTracking.tsx` 中的 ECharts 配置；不改变 Excel 导入、数据计算、筛选、日期范围或后端服务。

## 设计

### 自适应横坐标

- 根据当前日期点数量计算标签间隔，目标是在单张图中显示约 8–12 个日期标签。
- 始终显示首尾日期。
- 标签改为水平显示，重叠时由 ECharts 自动隐藏。
- 缩放条保留，布局下移并增大图表底部留白；缩放后的横轴仍按当前范围自适应抽样。
- 提示框继续显示被隐藏日期对应的完整日期和全部系列数值。

### 系列样式

- 为常用指标指定稳定颜色，避免不同图内重复使用同一种颜色。
- 主系列采用较粗实线；对照系列采用虚线或点划线；数据点保留小圆点以便定位。
- 柱状系列使用低饱和填充色与圆角顶部，折线系列不使用柱状样式。
- 双 Y 轴图中，右轴名称和轴标签颜色匹配对应系列。

### 验证

- 为日期标签间隔计算添加单元测试：短、中、长日期序列均满足首尾可见且不会生成零或负间隔。
- 执行 `npm run lint` 与 `npm test`。
- 使用已有 Excel 数据在页面检查：日期不再与缩放条重叠；图例、颜色、线型和提示框一致。

## 非目标

- 不接入 Oracle、SQLite 或新增任何数据源。
- 不调整外输数据的解析和汇总公式。
- 不修改其他页面图表。
