# 区块生产动态生成器统一区块设计

## 目标

“区块生产动态生成器”的区块选择、曲线统计和 Excel 导出使用同一套透明、确定性的区块归类规则。选择统一后的区块时，将其包含的所有原始子区块按日期汇总为一条生产动态曲线，同时保留底层原始数据和单井原始区块名称。

## 归类规则

| 原始区块 | 统一区块 |
| --- | --- |
| `246块L*` | `高246` |
| `3块L*` | `高3` |
| `3618块L*` | `高3618` |
| `3624块`南、北及各层 | `高3624` |
| `高21`南、北 | `高21` |
| 其他区块 | 保持原名 |

匹配时忽略区块名称中的空白，并兼容中文、英文括号。规则采用前缀和明确名称匹配，不使用模糊相似度，避免区块误归类。

## 数据流程

1. 后端读取原始区块列表，对名称应用统一归类规则并去重，返回给前端。
2. 前端区块多选框仅显示统一区块名称。
3. 用户选择一个或多个统一区块并生成曲线时，前端把统一区块名称传给 `/api/chart/block`。
4. 后端对每条原始生产记录的区块名称应用相同规则，筛选所有归属于所选统一区块的记录。
5. 后端沿用现有按日期聚合口径，将同一日期、同一统一区块下的数据汇总。
6. 页面曲线和 Excel 导出使用接口返回的统一名称与汇总结果。

## 汇总口径

- 日产油、日产液等可加指标：按现有接口口径求和。
- 含水率等比率指标：沿用现有接口基于汇总基础量的计算方法，不直接对各子区块百分比做简单相加。
- 多选区块：沿用当前页面逻辑，将所选统一区块的数据共同生成曲线。
- 原始数据库记录、单井记录及原始区块名称不修改。

## 代码边界

- 区块名称归类由一个可复用的纯函数负责。
- 前端列表展示与后端查询使用同一规则含义，避免只改显示不改统计。
- 不修改与“区块生产动态生成器”无关的页面和统计逻辑。

## 验证标准

1. 区块选择列表中不再分别出现上述同组的原始子区块。
2. 选择“高3624”时，接口统计包含所有 `3624块`南、北及各层数据。
3. 选择“高21”时，接口统计包含高21南、北数据。
4. 其他未命中规则的区块名称和数据范围不变。
5. 曲线数据和 Excel 导出数据一致。
6. 归类单元测试、接口统计测试和生产构建通过。
