# 已选井效果参考设计

## 目标

在“措施选井注汽选井”页面中，将已选井的效果参考区域放在“候选井与月度注汽计划”之前。该区域针对当前月度计划中一口选定井展示近三轮停注汽后的日产油曲线、三轮关键指标和当前候选井范围内的同类井。

## 可见条件与交互

- 仅当当前页面已生成月度注汽计划时显示。
- 下拉框只列出当前计划中人工决定为“纳入”或“锁定”的井。
- 默认选择排名第一的可展示井；切换井号后刷新该井的曲线、指标和同类井。
- 不同时展示所有计划井图表，避免最多 30 口井的曲线相互遮挡。

## 近三轮日产油曲线

- 从阶段产油数据中取选中井最近三轮有效周期。
- 每轮以该周期的停注汽日期为第 0 天进行对齐。
- 只保留停注汽后第 10 天至第 310 天的生产日报日产油点。
- 横轴为“停注汽后天数”，纵轴为“日产油”。
- 每轮一条曲线，缺失日期保留为空点，不以零值填补。
- 缺少停注汽日期、生产日报或有效周期时，接口返回具体缺失原因，前端显示空状态。

## 三轮关键指标

曲线下方按最近到最早顺序显示每轮：

- 停注汽日期
- 阶段产油
- 油汽比
- 周期注汽量

## 同类井

- 比较范围仅限本次重建生成的当前候选井。
- 排除当前选中井。
- 使用油汽比、阶段产油、稳定性、日数据完整性计算相似度。
- 按相似度降序展示前 10 口，并展示相似度、评分、油汽比、阶段产油。
- 没有可比较候选井时显示明确空状态。

## 后端与数据边界

- 新增按计划 ID 与井号读取的只读接口。
- 后端从当前阶段产油表读取最近三轮周期，从生产日报表读取日产油；日数据表仅用于重建同类候选井的完整性特征。
- 接口只返回当前计划中的井，避免使用未选中的井号查询。
- 不修改候选井评分、排序、计划生成和数据库结构。

## 验证

1. 单元测试验证按停注汽日期计算第 10 至 310 天窗口、缺失日期不补零、最近三轮排序和指标映射。
2. 单元测试验证同类井只来自当前候选井、排除目标井、最多返回 10 口并按相似度排序。
3. API 测试验证计划井查询、非计划井拒绝、无生产日报时缺失原因。
4. 前端测试验证新区域位于计划区域之前，展示切换控件、曲线空状态、指标和同类井。
5. 浏览器验证已生成计划时的实际显示与无数据提示。
