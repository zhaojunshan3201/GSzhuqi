# 措施选井模块设计

## 目标

在“措施跟踪”上方新增“措施选井”模块，对数据库内有历史注汽周期的井进行可追溯综合评价，输出综合排序和“建议注汽 / 备选井 / 不建议 / 数据待补全”分级。

## 数据范围

- 历史注汽周期数据提供实际注汽量、轮次、转抽时间及相关注汽参数。
- 历史生产数据提供注汽后的日油曲线和周期产油。
- `措施选井.xlsx` 用于批量导入或更新上轮参数，字段为：区块、井站、井号、上轮转抽时间、上轮轮次、上轮设计注汽量、上轮注汽最高压力、上轮排量、上轮是否注 N2、上次锅炉、上轮峰值产油、上轮见油时间、上轮周期产油。
- 仅对有历史注汽周期的井进行正式评分。缺失井号、转抽时间、实际注汽量或周期产油的记录不参与正式评分，并显示缺失原因。

## 综合评分

每口井的综合分为 0–100 分，均在区块内按分位标准化。

| 指标 | 分值 | 规则 |
| --- | ---: | --- |
| 历史油汽比 | 40 | 以近 3 轮为主、全部历史为辅；单轮油汽比 = 周期产油 / 实际注汽量。 |
| 历史周期产油 | 20 | 评价各历史注汽周期的总体产油效果。 |
| 上轮峰值产油 | 15 | 使用导入的上轮峰值产油。 |
| 上轮见油时间 | 10 | 见油越快，得分越高。 |
| 注汽参数匹配与稳定性 | 10 | 根据设计/实际注汽量、最高压力与排量的匹配和稳定性评分；异常或缺失扣分。 |
| 数据完整性 | 5 | 按参与评价的关键字段完整度计分。 |

评分结果必须保存原始指标值、指标得分、扣分原因和计算时间，以便复核；不会修改历史注汽或生产原始数据。

## 分级与列表

- **建议注汽**：达到建议阈值。
- **备选井**：达到备选阈值但未达到建议阈值。
- **不建议**：未达到备选阈值。
- **数据待补全**：无法完成有效评分。

模块默认展示建议井，并提供“推荐前 20 口”视图；筛选条件包括区块、站点和分级。阈值作为明确的后端常量集中管理，首版不提供前端配置界面。

## 页面与交互

模块入口位于左侧导航“措施跟踪”上方。

1. 顶部显示有效评价井、建议注汽、备选井、不建议/待补全的统计卡片，并提供 Excel 导入和重新计算评分操作。
2. 主体使用同页分栏布局：左侧为按综合分降序的选井列表；右侧为当前选中井的分析面板。
3. 点击左侧任一井，仅刷新右侧面板，不进入独立详情页；用户可连续切换其他井。
4. 右侧上半区显示该井最近 3 轮注汽后的采油曲线。各轮以转抽日为第 0 天对齐，横轴为转抽后天数，纵轴为日油，三轮用不同颜色显示。
5. 右侧下半区显示同 3 轮的参数表：轮次、转抽时间、设计/实际注汽量、最高压力、排量、N2、锅炉、峰值产油、见油时间、周期产油、油汽比。
6. 生产曲线或单轮字段缺失时，保留该轮记录并展示“数据缺失”，不用零值填充。

## 数据流与接口边界

1. Excel 上传服务校验表头并映射上轮参数；未识别列进入导入反馈。
2. 评价服务按井聚合历史注汽周期和生产日数据，计算每周期油汽比、评分、分级及近 3 轮展示数据。
3. 列表接口返回筛选后的排名、分级与摘要得分；单井接口返回评分依据、近 3 轮参数和对齐后的曲线点。
4. 任意导入成功后或用户手动触发时执行重新计算，并写入评分结果快照。
5. 同井同轮次导入必须去重；接口不改变原始生产和注汽数据。

## 验证范围

- Excel 既定表头正确导入，未识别列被明确反馈。
- 仅 1–2 轮、3 轮及以上历史均可评分或按规则标记待补全。
- N2 是/否、缺失字段、同分排序、跨区块数据和曲线缺失均有覆盖。
- 列表点击不改变路由；右侧曲线和近 3 轮参数随选中井原位刷新。
- 构建、类型检查和相关接口/评分单元测试通过。
