# 注汽管理菜单尾部顺序与图标调整设计

## 目标

调整“注汽管理”菜单中四项业务入口的显示顺序，并为“注窜项目台账”使用能表达注窜关联关系的独立图标。

## 范围

仅调整已有菜单项的显示顺序和一个图标；不修改路由、页签标识、权限、页面内容或数据加载逻辑。

## 菜单顺序

“注汽管理”保留既有前置业务链路：选井决策、方案与计划、施工监控、焖井转抽、生产响应。其后的尾部顺序固定为：

1. 效果评价
2. 注汽优化预测
3. 运行报告
4. 注窜项目台账

## 图标

“注窜项目台账”由当前与“选井决策”重复的靶心图标改为分支关联图标（`GitBranch`），表示注井与采油井之间的注窜关系。其他菜单图标保持不变。

## 验收标准

- 注汽管理菜单按上述顺序显示四项尾部入口。
- 点击四项入口仍打开原有页面。
- 注窜项目台账显示分支关联图标，选井决策仍显示靶心图标。
- 导航配置单元测试覆盖顺序与图标映射。
