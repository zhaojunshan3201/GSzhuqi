# 注汽业务菜单与注采状态地图升级设计

## 目标

将系统导航从按既有技术模块堆叠，调整为以注汽业务流程为主线；保留“系统概览”作为默认首页，并将“油井位图”升级为可筛选、可下钻、能够融合项目台账与历史注汽跟踪数据的“注采状态地图”。

本期不增加实时锅炉或施工采集接口，不创建无功能的“优化复盘”和“数据导入与同步”菜单。

## 页面定位

- **系统概览**：保留为默认首页，展示系统数据规模、模块入口、同步状态和整体运行情况。
- **注汽驾驶舱**：注汽业务管理首页，展示项目生命周期、生产效果、异常与待办。
- **注采状态地图**：通过空间视角展示注汽项目状态、历史跟踪状态、生产响应和异常。

## 项目管理业务视图

`InjectionProjectManagement` 复用同一项目台账，通过视图参数区分入口：

```ts
type InjectionProjectView =
  | 'plan'
  | 'construction'
  | 'soakTransfer';
```

- `plan`：显示月度计划导入、手工建项、导入历史和全部项目。
- `construction`：聚焦待注汽、注汽中项目以及计划与实际执行偏差。
- `soakTransfer`：聚焦焖井中、待转抽项目和逾期待办。

三个入口不复制项目数据，不创建独立台账。状态流转继续使用现有项目状态模型。

## 注采状态地图

### 生命周期图层

默认显示：

- 待注汽
- 注汽中
- 焖井中
- 待转抽
- 生产响应
- 已关闭
- 数据待补全

### 关注图层

保留现有高含水井、重点井等人工分类，作为独立的“关注图层”。关注图层不能覆盖或改变项目生命周期数据，只用于视觉强调和辅助筛选。

### 筛选条件

- 区块
- 生命周期状态
- 计划月份
- 异常类型
- 是否逾期
- 井号搜索

筛选同时影响地图标点、图例统计和无坐标井列表。

### 地图统计条

- 地图内井数
- 注汽中
- 焖井中
- 待转抽
- 生产响应
- 异常井
- 无坐标井

### 井点详情

点击井点打开右侧详情抽屉，展示：

- 井号、区块、井站
- 当前项目状态和数据来源
- 计划与实际注汽时间
- 计划与实际注汽量
- 焖井天数、计划转抽日、逾期天数
- 当前日产油、累计增油、油汽比、评价
- 当前异常、负责人
- 进入项目、查看生产响应、查看效果评价

移动端详情抽屉显示为底部面板。

### 无坐标井

没有有效坐标的井进入“待补坐标”列表，不生成默认位置或虚假坐标。管理员继续使用现有标定功能补录坐标。

## 数据融合规则

1. 同井存在当前有效项目时，生命周期状态以项目台账为准。
2. 历史注汽跟踪数据补充生产效果、评价和异常。
3. 没有有效项目时，生命周期回退到历史注汽跟踪状态。
4. 项目状态来源显示为“项目台账”，历史回退显示为“历史跟踪数据”。
5. 同井多条项目记录取未关闭且更新时间最新的项目；全部关闭时取最新关闭项目。
6. 缺失数值保持 `null`，页面显示 `--`，不得转换为零。

## 下钻关系

```text
注汽驾驶舱异常
        ↓
注采状态地图定位井
        ↓
井点详情
        ↓
方案与计划 / 施工监控 / 焖井转抽 / 生产响应 / 效果评价
```

地图详情的项目入口携带 `projectId`；生产响应和效果评价携带井号。已有驾驶舱下钻继续兼容。

## 错误处理

- 地图接口局部字段缺失时仍返回井点。
- 项目查询失败时回退历史跟踪状态，并标明数据来源。
- 地图接口整体失败时保留上一次成功结果，显示错误和重试按钮。
- 无坐标井只进入待补坐标列表。
- 无法匹配项目的历史井不报错。

## 权限

- 地图状态、筛选和详情对当前只读用户开放。
- 井位标定、分类管理和坐标删除继续仅管理员可用。
- 本期不新增项目写权限模型。
