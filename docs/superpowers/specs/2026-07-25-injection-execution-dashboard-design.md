# 注汽计划执行统计看板设计

## 目标

将计划执行对比从单井列表优先调整为统计看板和图表优先，避免跨周期实际记录被误判为本轮计划偏差。

## 对比范围与规则

- 默认只纳入当前计划月份及前一个自然月的计划。
- 实际开注或停注与计划对应日期相差超过 60 天时，标识为“疑似非本轮”，不计入提前、滞后或按计划统计。
- 计划工艺不再展示内部值 `monthly-import`，统一显示“月度注汽计划”；实际工艺缺失显示 `--`。

## 界面

顶部统计卡展示：计划井数、已执行、按计划、提前、滞后、未执行、疑似非本轮。

图表包括：开注偏差分布柱状图、停注偏差分布柱状图、按锅炉汇总的计划注汽量与实际注汽量对比图。

下方保留“偏差井明细”，默认展示提前、滞后、未执行和疑似非本轮井，并允许切换查看全部。明细保留计划/实际开停时间、锅炉、注汽量、工艺及状态。

## 验证

测试覆盖两个月窗口、60天疑似非本轮排除、内部工艺显示替换、统计计数及锅炉汇总。前端构建验证图表和明细筛选可用。
