# 注窜项目日产油汇总两位小数显示设计

## 目标

在注窜项目“项目概览”中，将以下三个汇总字段固定显示两位小数：

- 期初日产油合计
- 最新日产油合计
- 日产油合计变化

例如，`85.3` 显示为 `85.30`，`0.29999999999999716` 显示为 `0.30`。

## 设计

仅在 `ChannelingProjectManagement` 的显示层格式化这三个字段。新增一个小型数值显示函数：数值使用 `toFixed(2)` 输出；`null`、`undefined` 或非有限数值继续显示“暂无数据”。不修改汇总计算、接口返回值、数据库字段或其他统计卡片。

## 测试

扩展项目概览交互测试，覆盖：

- 一位小数补齐为两位小数；
- 浮点计算误差按两位小数舍入；
- 缺失值仍显示“暂无数据”。

## 验收标准

项目概览中的三个指定字段始终显示两位小数，其他字段和底层数值保持现状，相关测试及构建通过。
