# 外输跟踪计量站选择器紧凑化设计

## 目标

将“外输跟踪”页面的计量站多选控件从固定展开的原生列表改为紧凑的单行入口，减少筛选区域的纵向占用，同时保留多选能力与当前筛选行为。

## 交互与界面

- 默认展示一枚约 40px 高的选择按钮，标签保持“计量站（可多选）”。
- 按钮优先展示已选站点名称，例如“已选 3 个：10站、12站、14站”；内容超出可用宽度时省略，不改变控件高度。
- 点击按钮后显示定位在控件下方的浮层。浮层内逐项显示复选框和站点名称，已选项保持勾选。
- 勾选或取消勾选立即更新当前筛选；点击浮层外部时收起浮层。
- 现有“全选计量站”操作继续将全部站点设为已选；上传成功后仍默认选中所有站点。

## 技术边界

- 仅修改 `src/components/ExternalTransferTracking.tsx` 的计量站控件及其局部状态处理。
- 不调整外输记录解析、汇总、图表、日期筛选、上传接口或数据结构。
- 不引入新的第三方依赖；使用已有 React 状态、引用和 Tailwind 工具类。

## 验证

- 新增/扩展组件可测试的状态逻辑测试，覆盖默认全选、单项切换和全选恢复。
- 执行 `npm test`、`npm run lint` 与 `npm run build`。
- 在 `http://localhost:5001` 手动确认控件默认高度为单行、可展开多选、点击外部可收起，且图表随筛选更新。
