# 运行日志菜单位置调整设计

## 目标

将“运行日志”从“基本情况”菜单组中移出，作为紧跟“产量掌控”菜单之后的独立菜单项显示。

## 界面与交互

- “运行日志”不显示在“基本情况”或“产量掌控”菜单组内。
- 它以无分组标题的独立菜单项形式紧接“产量掌控”组之后。
- 点击后仍进入既有运行日志页面；页面内容、标题、状态和错误展示均不变。

## 技术边界与验证

- 仅调整侧边栏导航数据结构和渲染位置，保持现有 tab 标识 `runtimeLogs`。
- 不改动日志页、同步逻辑、接口或数据状态。
- 更新导航测试，验证该项目不属于 overview/production 组且渲染在 production 组之后；运行 `npm test` 和 `npm run build`。
