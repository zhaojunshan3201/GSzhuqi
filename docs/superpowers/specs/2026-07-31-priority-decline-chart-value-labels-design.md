# 上月递减率图数值标签设计

## 目标

在重点情况分析页的“上月递减率”横向柱状图上直接显示每个区块的递减率数值，减少用户依赖坐标轴或悬浮提示读取数据的操作。

## 展示规则

- 每根有效柱条显示一个百分比标签。
- 数值保留一位小数，例如 `31.2%`、`-17.8%` 和 `0.0%`。
- 正值标签显示在柱条右端外侧。
- 负值标签显示在柱条左端外侧。
- 标签使用中性深色文字，不改变现有正值红色、负值绿色的柱条配色。
- 保留现有区块排序、横向方向、坐标轴百分比格式和 tooltip。

## 布局与边界

- 增加图表左右侧留白，为柱端外侧标签预留空间。
- 标签不得被图表容器裁切。
- 接近零的短柱仍在对应方向的柱端外侧显示完整数值。
- 图表继续最多展示当前逻辑选取的 10 个有效区块。

## 实现范围

仅调整 `src/components/PrioritySituationAnalysis.tsx` 中递减率 ECharts 配置：

- 为柱状系列启用 `label.show`。
- 使用数据正负值动态返回标签位置：正值为 `right`，负值为 `left`。
- 使用 formatter 输出一位小数百分比。
- 调整 grid 左右边距并包含标签空间。

不修改 API、递减率算法、数据排序、颜色语义或其他页面区域。
