# 最优运行推荐可视化设计

## 目标

将“最优运行推荐 Top 3”从文字卡片升级为可比较、可解释的图表与表格决策看板。

## 组件

1. 横向方案对比表：注井顺序、注汽量、压力、排量、焖井、转抽、锅炉、净增油、波动、注窜、占产、成本、收益、评分、置信度。
2. 综合评分雷达图：净收益、稳产性、注窜风险、占产影响、资源匹配度、数据完整度。
3. 收益损失瀑布图：增油收入、蒸汽成本、作业成本、注窜损失、占产损失、净收益。
4. 运行参数柱状图：注汽量、压力、排量、焖井天数、转抽窗口。
5. 风险稳定性散点图：横轴产量波动、纵轴综合风险、气泡大小净收益。

默认突出综合最优方案；未知值显示待补全，不转换为零。所有图表使用 ECharts aria、tooltip、空态和固定色彩语义。
