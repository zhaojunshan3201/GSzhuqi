# 油井位图分类设计

## 目标

在“油井位图”页面让管理员创建分类、设定颜色与优先级，并将已标定井号加入分类。地图为生产井显示一个分类颜色。

## 分类管理

- 管理员通过“分类管理”打开侧边面板。
- 每个分类包含名称、颜色、优先级和备注。
- 优先级数字越小，显示优先级越高。
- 分类可编辑、删除；删除分类时仅删除分类关系，不删除井位标定。

## 井号归类

- 分类面板中可搜索已标定井号，并加入或移除当前分类。
- 一个井号可归入多个分类。
- 未标定井号不能加入分类；需先完成井位标定。

## 地图显示规则

- 默认红点代表未命中任何可见分类的生产井。
- 井号命中多个分类时，只显示优先级最高且“已开启显示”的分类颜色。
- 分类显示开关关闭后，不参与颜色计算；若存在下一优先级可见分类，则显示其颜色。
- 分类颜色仅覆盖生产井点色，不改变井位、缩放、拖拽或标签设置。

## 验收标准

1. 管理员可新建、编辑、删除分类，且数据刷新后保留。
2. 管理员可将已标定井号加入或移出分类。
3. 多分类生产井按可见分类中的最高优先级显示一种颜色。
4. 关闭一个分类显示后，地图立即回退到下一可见分类颜色或默认红色。
