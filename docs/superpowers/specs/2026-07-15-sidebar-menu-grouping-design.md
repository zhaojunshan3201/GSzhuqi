# 侧边栏菜单分类设计

## 目标

将现有扁平的侧边栏菜单重组为五个手风琴分类，减少菜单拥挤，同时保持每个既有页面的入口与行为不变。

## 菜单结构

| 分类 | 栏目 |
| --- | --- |
| 基本情况 | 系统概览、油井位图、井温监控 |
| 分析系统 | 单井分析、区块分析、对比分析、检泵分析、占产分析 |
| 重点情况 | 重点监控、含水化验、检泵跟踪 |
| 措施项目 | 措施选井、措施跟踪、措施分析 |
| 产量掌控 | 产量预测 |

## 交互与状态

- 分类采用手风琴样式：同一时间只展开一个分类。
- 初始状态以及切换页面后，当前 `activeTab` 所属的分类自动展开。
- 点击分类标题可展开或收起；展开新分类时自动收起其他分类。
- 点击子菜单时，沿用现有 `setActiveTab` 页面切换逻辑和图标。
- 用户信息、退出系统和侧栏底部的系统状态保持不变。

## 实现边界

- 将菜单定义为分类配置数据，并以该数据渲染分组和子菜单。
- 不修改既有页面内容、服务端接口、数据库或页面路由语义。
- 删除原有扁平菜单渲染所产生的重复 JSX；不做与导航无关的重构。

## 验证

- 添加菜单配置/分类归属的自动化测试，覆盖五个分类及全部 15 个栏目。
- 执行 `npm test`、`npm run lint` 和 `npm run build`。
