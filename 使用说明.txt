3. 安装依赖
在项目根目录下执行以下命令，安装后端和前端所需的所有库：
code

这会自动安装 oracledb (数据库驱动)、express (后端框架)、react (前端框架) 等。

5. 启动项目
执行以下命令启动开发服务器：
code
Bash

启动后会发生什么？
后端启动：Node.js 会启动一个 Express 服务器（默认端口 3000）。
前端加载：Vite 会作为中间件运行，自动编译 React 代码。
自动连接：后端会自动尝试连接您的 Oracle 数据库。
访问地址：您可以在浏览器中打开 http://localhost:3000 即可看到管理系统界面。
